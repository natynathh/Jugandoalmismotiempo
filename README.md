# La tienda de los mundos 🎮

Primera versión interactiva del proyecto **El mundo jugando al mismo tiempo**.

Una mercadera RPG llamada Lira presenta videojuegos como reliquias y permite explorar estadísticas, la metáfora de mundos virtuales habitados y la historia de Mats Steen (Ibelin).

## Vista previa
Este repositorio contiene una demo estática en `docs/` para GitHub Pages. Para activarla: **Settings → Pages → Deploy from a branch → main → /docs → Save**.

**Importante:** la vista previa de GitHub Pages muestra cifras de demostración, no datos en vivo. La versión completa incluye una ruta de servidor que intenta consultar jugadores activos de una selección de juegos en Steam. El reconocimiento de gestos es experimental.

Consulta `GITHUB-PAGES.md` para los pasos y `LEEME-NATH.md` para ejecutar el proyecto.
